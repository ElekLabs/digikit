# Project manager

Inspect the current project on the device and browse the device's projects in Workbench. Both views are read-only.

- On the device, open **SETTINGS > PROJECT** to see the current project's slot, name, and digikit save status. Press **NO** to close the screen.
- In Workbench, open **Project manager** and select a project to see its save stamp and the modules recorded in its digikit data. The list marks the current project. Choose **More projects** to load the next page.

Project manager requires the digikit UI and project services.
